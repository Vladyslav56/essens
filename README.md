## Technologický stack

- React (Vite)
- Tailwind CSS
- JavaScript (ES6+)

## Jak spustit projekt lokálně

1. Naklonujte repozitář nebo otevřete složku s projektem v terminálu.
2. Nainstalujte potřebné závislosti:

npm install / yarn

3. Spusťte lokální vývojový server:

npm run dev / yarn dev

4. Otevřete v prohlížeči adresu vypsanou v terminálu (zpravidla http://localhost:5173).
